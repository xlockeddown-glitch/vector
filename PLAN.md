# VECTOR — the plan

Two systems. That is the whole game.

1. **Draft once** at the start (Hearthstone Arena).
2. **Tower defense** after that (plant, survive waves).

A third layer sits on the draft so runs feel different:

3. **Signals** — 2 extra cards that change the rules of this run (Balatro jokers, not called jokers).

Cards should look like real cards: Hearthstone layout, painted art, space colors.

No draft between waves. No draft mid-fight.

---

## A run

1. Your bound craft is already yours (Boost / Shrike / Auger). That is your “class.”
2. **Draft** — about 6 picks, 3 cards, take 1.
3. **Plant** guns on moons.
4. **Survive 12 waves.** That is a win.
5. Then pick:
   - **Keep flying** — endless, harder, high score.
   - **Return** — take Credit, new run, new draft.

If you die before wave 12, the run is over. Draft again.

---

## The draft (Arena)

Always 3 cards. Pick 1. Same kind. Same rarity so you are choosing a job, not loot.

**Pick 1 — the set**
Three offers. Each offer is **two guns that already work together** (like Arena’s legendary group).

Examples:
- Lance + Halo (pierce + freeze)
- Well + Corona (pull + wide wipe)
- Ion + Mine (jump + bombs)
- Crater + Beacon (splash + payday)

You pick one set. You now have a plan.

**Picks 2–5 — fill moons**
Normal 3-pick-1. Mostly guns. Sometimes a second craft.
End with enough for the moons you have (about 3–6 guns). Not 12. Not 30.

**Picks 6–7 — Signals**
3-pick-1 of rule cards. **2 slots.** Drafted here, not later.

Then plant. Fight. No more cards.

---

## The fight (simple TD)

Enemies walk the warp lane.
You plant on moons.
Drag a craft onto a gun to slam.
Lives. Credit.
Wave ends, next wave. No pack. No pause.

First wave is basic enemies so you learn the guns.
Later waves add more / tougher ones. Normal TD curve.
No “scare” events. No extra HUD warnings.

Combat HUD during a fight: **lives, credit, wave.**

---

## After a win

Same screen, two buttons:

- **Keep flying** — waves keep coming, hotter, score goes up. Cash out whenever.
- **Return** — Credit in, title, new draft.

That is Bloons (round 40 is a win, you can keep going) plus Balatro endless.

## Signals (not jokers)

A card you draft. It does not go on a moon. It sits on the run.
One sentence. Always on.
2 slots.

If you cannot see it happen in the lane, it is a percent and it does not ship.
“+6% damage” is banned. “Ion jumps one extra time” is a Signal.

No silent negatives. If a Signal has a trade, the sentence says both sides.

### Gun Signals

| Signal | Sentence |
|---|---|
| Twin spark | Ion jumps one extra time |
| Deep lance | Lance punches through one more hull |
| Long freeze | Halo holds longer |
| Fat crater | Crater bowl is wider |
| Extra mine | Mine drops a second charge |
| Hard well | Well pulls harder |

### Craft Signals

| Signal | Sentence |
|---|---|
| Fat slam | Slam hits much harder |
| Double dock | Dock heals more |
| Fast craft | Crafts fly quicker |

### Lane / payout Signals

| Signal | Sentence |
|---|---|
| Ore vein | Kills pay extra Credit |
| Ghost hull | First leak does not count |
| Slow rim | Enemies crawl on the last stretch |
| Wide shade | All guns reach farther |
| Hot lane | Guns shoot faster. Enemies walk faster. |

Combo is the point:
- Lance + Halo + Long freeze = plates never arrive
- Well + Corona + Wide shade = swarms vanish
- Ion + Twin spark + Ore vein = chain-kill money run

Same 10 guns. Different Signals. Different run.

Other names if Signal is wrong: Cores, Payloads, Anomalies. Default: **Signals**.

## Cards

Hearthstone **shape**. VECTOR **paint**.

- Playing-card size (2.5 × 3.5). Big on the pick screen. Do not shrink to fit a grid.
- Painted art, not a product photo. The gun looks like a character.
- Oval portrait window
- Name on a bar (VECTOR font)
- Gem = rarity (on top, like a mana crystal)
- One line of text. Example: “Punches through the line.”
- Space colors: dark, frost, steel, stars. Gold filigree optional. Steel + frost rim is fine if gold fights the theme.

Signals use the same card body. Kicker says SIGNAL so they are not mixed up with guns.

When you pick, the card slams forward, then you plant it (guns) or it slots onto the run (Signals).

## What we steal / skip

| Steal from | Skip |
|---|---|
| Arena: 3 pick 1, then play | 30-card decks |
| Arena: start with a set that synergizes | Drafting after every wave |
| Balatro: 2 rule cards, win then endless | Calling them jokers |
| Balatro: simple sentences that stack | A shop every round |
| Kingdom Rush: readable path, clear win | Arknights gacha |
| Bloons: win at a round, then optional endless | Mid-run relics / part percents |
| STS relics: always-on, not a tower | STS “add a card after every fight” |

Monster Train and Tower Tactics are the closest card+TD games. They keep giving cards during the run. We do not copy that.

## What to cut from the current game

These fight the loop:

- Packs between waves
- Packs mid-fight / `pickPause`
- Part cards with percents
- Ban
- Extra pack types
- Orbit / Bond / Forge on the combat HUD
- Forever stamps that duplicate Signals
- Opening of 5+ unrelated packs with no “set”

Keep:

- Guns on moons, crafts in the sky
- Lives + Home
- Credit as the one wallet
- Bound main craft
- Gem rarity
- Gun names (Lance, Halo, Well, Ion…)
- Vault on title / after a run (hangar, not the path)

---

## Build order

1. **Cards look like cards.** Size, painted art, oval, name bar, one line.
2. **Opening draft only.** Kill between-wave and mid-wave packs.
3. **Win at wave 12.** Keep flying / Return.
4. **Signals.** 2 slots, last picks of the opening.
5. Strip leftover chrome that duplicates Signals.

Cards first. If the draft still looks like a menu, the loop will still feel cheap.

## Open forks (only these)

- Name: Signals vs Cores vs Payloads
- Win at 12 waves vs 10 vs 15
- 2 Signal slots vs 3
- Gold HS frame vs steel/frost frame

Defaults: **Signals, 12 waves, 2 slots, steel/frost frame** (space, not tavern).

## Example run (so this is not abstract)

You tap Play. Bound craft = Boost.

1. Set: Lance + Halo
2. Gun: Well
3. Gun: Ion
4. Gun: Corona
5. Signal: Twin spark
6. Signal: Long freeze

Plant four guns. Boost in the sky.
Ion jumps extra. Halo freeze lasts.
Hold 12 waves. Win.
Keep flying for score, or Return.
